Custom trackpad gestures on Mac

How to run any keyboard shortcut with a tap on your MacBook trackpad.

Your Mac's trackpad is great at pointing and scrolling, but it can't run the keyboard shortcuts you use all day. macOS gives you a fixed set of gestures in System Settings › Trackpad (swipe for Mission Control, pinch for Launchpad), and you can't point them at your own shortcuts.

TapDeck fixes that. It turns taps, double taps, triple taps and holds with 3, 4 or 5 fingers into the shortcut you need, and it knows which app you're in, so the same gesture does the right thing everywhere.

What a tap can do

  • 3-finger tap opens a new tab in Chrome, Safari, Firefox, Arc, Dia and every terminal (Ghostty, Terminal, iTerm2, Warp).
  • 4-finger tap brings back the browser tab you closed by mistake.
  • 3-finger hold opens Mission Control. 5-finger tap plays or pauses music.
  • Code editors (VS Code, Cursor, Zed, Xcode): command palette, run, terminal, back and forward.
  • Claude Code and Codex: run /compact, /usage or /model without typing them.
  • 5-finger double tap shows a cheat sheet of every gesture for the app in front.

How to set it up

  1. Install TapDeck. Get it here, drag it to Applications and open it. It lives in your menu bar.
  2. Allow Accessibility when asked, so TapDeck can press shortcuts for you.
  3. Switch on packs for the apps you use in Settings › Packs. There are 46, from Chrome and Xcode to Obsidian, Blender and OBS.
  4. Make your own gesture: choose Add Shortcut, do the gesture on the real trackpad, pick what it runs (a keystroke, an app, a command from the app's menus, or a typed command) and save.
  5. Forget one? Tap with five fingers twice for the cheat sheet.

Will it fight the normal Mac gestures?

No. TapDeck only listens for taps and holds. Pointing, clicking, scrolling and the system swipes keep working exactly as before, and it pauses for a moment while you type so a resting palm doesn't trigger anything.
